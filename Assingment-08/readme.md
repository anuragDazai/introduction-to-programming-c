# Q8 — Area of Circle, Triangle, Square and Rectangle

## Description
This program calculates the area of a circle, triangle, square, and rectangle.

## Formulas
- Circle = `PI × radius × radius`
- Triangle = `1/2 × base × height`
- Square = `side × side`
- Rectangle = `length × width`

## Input
- Radius of circle
- Base and height of triangle
- Side of square
- Length and width of rectangle

## Output
The program displays the area of all four shapes.
